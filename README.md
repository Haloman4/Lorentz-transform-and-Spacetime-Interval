# Lorentz-transform-and-Spacetime-Interval
Sympy-based Calculator for Special Relativity functions

This code does some basic calculations corresponding to Special Relativity. You insert your 4 vectors(usually space and time basis vectors) and a velocity, which must be a portion of the speed of light(i.e. instead of 4,300 km/s second or something like that, put 0.01 for v). The code will take the 4 vectors for t, x, y and z, then put out the new 4 vectors for the t and x directions. As a bit of a double-checking mechanism, the code also returns the spacetime interval for the 4 vectors, to make sure that ds^2 is invariant.
